# Garçom Digital - PWA

Sistema web desenvolvido para auxiliar o atendimento em
restaurantes e estabelecimentos comerciais.

## Objetivo

Digitalizar o processo de pedidos, permitindo maior organização
e agilidade no atendimento.

## Funcionalidades

- Cadastro de produtos
- Cardápio digital
- Controle de mesas
- Registro de pedidos
- Visualização do pedido
- Interface responsiva
- Funcionamento como PWA

## Tecnologias

- HTML
- CSS
- JavaScript
- PWA
